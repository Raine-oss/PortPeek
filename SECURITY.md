# Security Policy

## Supported Versions

Security updates are provided for the latest minor release branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | Yes                |
| < 0.2.0 | No                 |

---

## Reporting a Vulnerability

If you discover a potential security issue in PortPeek, please do not file a public issue on GitHub.

Instead, report vulnerabilities privately by emailing the maintainers or opening a private security advisory through the GitHub repository:

- Repository: https://github.com/Raine-oss/PortPeek/security/advisories/new

Please include:
- A detailed description of the issue
- Steps or code to reproduce the issue
- Affected operating system and architecture
- Potential impact

---

## Authorized Usage and Network Ethics

PortPeek executes real TCP connect scans (three-way handshake). Performing network scans against systems without explicit permission may violate organizational policies or applicable laws. PortPeek is designed for developers, system administrators, and infrastructure engineers to diagnose connectivity on localhost, internal staging environments, or systems they are authorized to test.
